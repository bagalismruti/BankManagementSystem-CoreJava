# Bank Management System - Core Java

## Overview

A console-based Bank Management System developed using Core Java. The project demonstrates Object-Oriented Programming concepts, Collections, Exception Handling, File Serialization, and Design Patterns.

## Features

- Create Savings and Current Accounts
- Deposit Money
- Withdraw Money
- Transfer Funds
- View Mini Statement
- Display All Accounts
- Close Account
- Monthly Interest/Fee Processing
- Persistent Data Storage using Serialization

## Technologies Used

- Java
- Maven
- OOP
- Collections (HashMap, ArrayList)
- Exception Handling
- File Serialization
- Singleton Pattern
- Factory Pattern
- Observer Pattern

## Project Structure

```
src
 └── main
      └── java
           └── com.bank
```

## How to Run

1. Clone the repository.
2. Open it in IntelliJ IDEA.
3. Run `Main.java`.
4. Use the console menu to perform banking operations.
